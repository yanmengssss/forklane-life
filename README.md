# Forklane · 小城普通人

一个可直接在浏览器打开的互动影游示例。玩家在小城的人生岔路口做选择，观看不同的视频片段并走向不同结局。

## 在线体验

GitHub Pages 部署完成后访问：<https://yanmengssss.github.io/forklane-life-demo/>

## 本地体验

下载 `index.html` 后直接用浏览器打开即可。视频、图片、剧情和交互都嵌入在这一个文件中，无需登录、服务器或构建步骤。

## 说明

本仓库只发布游戏成品，不包含生成流程、原始素材或平台后端。`index.html` 约 34 MB，初次打开需要等待视频数据加载。
